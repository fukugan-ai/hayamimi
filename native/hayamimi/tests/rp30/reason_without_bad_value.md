`fallback` の event の `stage` の値は、`hayamimi` が `source`、`punct`、`recognizer`、`vad`、`asr`、`events`、`replace`、`speaker`、`ingest`、`capture`、`translate`、`lid`、`second_opinion`、`refine`、`refine_punct` の 15 個、中継が `translate` と `sink` である。
`reason` の値は、`hayamimi` が `no_device`、`driver_unreadable`、`session_failed`、`missing`、`unreadable`、`memory_budget`、`library_unavailable`、`in_use`、`device_missing`、`provider_mismatch`、`spawn_failed` の 11 個である（`unreachable`、`unsupported_target` は中継の場面で使う）。
