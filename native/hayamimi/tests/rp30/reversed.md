`fallback` の event の `stage` の値は、`hayamimi` が `refine_punct`、`refine`、`second_opinion`、`lid`、`translate`、`capture`、`ingest`、`speaker`、`replace`、`events`、`asr`、`vad`、`recognizer`、`punct`、`source` の 15 個、中継が `translate` と `sink` である。
`reason` の値は、`hayamimi` が `spawn_failed`、`provider_mismatch`、`device_missing`、`in_use`、`library_unavailable`、`memory_budget`、`unreadable`、`missing`、`session_failed`、`driver_unreadable`、`no_device`、`bad_value` の 12 個である（`unreachable`、`unsupported_target` は中継の場面で使う）。
