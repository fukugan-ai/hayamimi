## 採らない手段

| 採らない手段 | 理由 |
|---|---|
| 進み具合を `state.json` だけに置く | git の外に在り公開の repo に載らないので、読み手がどの slice が済んだかを見られない |
| `rust_port.ja.md` の slice の表に状態の列を足す | merge のたびに設計が動き、「通った」を定める所と通った記録が混ざる |
| 行番号で指す | 直すたびに動くので、slice と commit の名前で指す |
