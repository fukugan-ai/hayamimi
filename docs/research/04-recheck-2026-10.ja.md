## 速度と品質に効きそうな変化

設計は、認識器を非 streaming のまま VAD の区切りに掛け、速報を約 0.5 秒ごとに解き直す形である（`rust_port.ja.md` の 78 行目）。
`goals.md` の 56 行目は、高精度な日本語 streaming model が出たら増分デコードを再評価するという条件を残している。
次の事実は、その条件に関わる。

**日本語で動く streaming ASR**

- Moonshine v0.1.5（2026-08-24）に、日本語の streaming（small と tiny）が入った。MIT。8 月の文書は英語のみと書いている（B35）。
- Nemotron 3.5 ASR Streaming 0.6B（2026-06-04）は日本語（ja-JP）を含む 40 locale で、chunk は 80、160、320、560 ms と 1.12 秒。FLEURS の日本語 CER は 80 ms で 13.87、1.12 秒で 11.48。cache-aware FastConformer と RNN-T。license は OpenMDW-1.1。8 月の 4 本に記述は無い。
- sherpa-onnx は Nemotron 3.5 の runtime を 2026-06-12 に取り込み（PR 3671）、docs に 560 ms の int8 package（2026-06-11）が載る。言語は stream ごとに `language` で選ぶ。
- Voxtral Realtime（2026-02-04）は 13 言語に日本語を含み、遅延は sub-200 ms から 2.4 秒まで設定でき、Apache 2.0。API は $0.006/分。vLLM の `/v1/realtime` で使える（D15、B30）。
- Qwen3-ASR は streaming を持つが、vLLM の backend だけで、batch と timestamp は返せない。日本語は 52 の言語と方言に含まれる。Neosophie の日本語 CER は 0.140 で、表の最良である（D12、D13）。
- sherpa-onnx の docs で日本語として載る物は、非 streaming の Zipformer（ReazonSpeech）と Parakeet-TDT-CTC-0.6B-ja である。Moonshine の日本語 streaming と Voxtral Realtime が sherpa-onnx で動くかは、確かめていない。

**日本語の精度の比較（別の測り）**

Neosophie の 20 clip（約 580 秒、RTX 5090）では、CER が Qwen3-ASR-1.7B 0.140、turbo 0.184、Voxtral-Mini-4B-Realtime 0.212、Granite Speech 4.1 2B 0.262、Cohere Transcribe 0.297、Parakeet-TDT-0.6B-v3 0.321、reazonspeech-nemo-v2 0.329、reazonspeech-k2-v2 0.445、kotoba-whisper-v2.0 0.495 である。
8 月の文書が日本語特化の代表とした kotoba-whisper は、この表で最下位である。
この組と `goals.md` の scorecard（日本語 CER 5.8%、実放送音声、beam search）は clip も採点も別で、並べて比べられない。

**道具の版**

- 設計が固定した sherpa-onnx 1.13.8、ONNX Runtime 1.31.0、CUDA 13.4.3、cuDNN 9.27、`ort` 2.0.0-rc.14 は、2026-10-14 時点で最新である（E1、E3、E5、E6、E8）。
- llama.cpp は b11609 に進んだ（E7）。ORT には CUDA の plugin EP の v0.2.0（2026-10-08）と v0.3.0（2026-10-09）が出ている。v0.3.0 の release は SM120 の FP4 QMoE の修正を載せる。
- whisper.cpp v1.9.5、CTranslate2 v4.8.3、Silero VAD v6.2.3（2026-09-23）、pyannote-audio 4.0.7（2026-06-30）が、各 repo の最新である。

**訳の model（8 月の 4 本は翻訳を扱っていない）**

- CAT-Translate の family は 0.8B、1.4B、3.3B、7B（論文 2026-06-19）。BLEU の平均は 3.3B が 36.16、7B が 37.68。card の比較に TranslateGemma-12b-it の 32.24 が在る。
- TranslateGemma は 2026-01-15 公開で、4B、12B、27B、55 言語。公式の記事は日本語を名指ししていない。
- LFM2-350M-ENJP-MT は 0.4B で日英の双方向、GGUF が在り、card は遅延を「near real-time」とだけ書く（数は無い）。
