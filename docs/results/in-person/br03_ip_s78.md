## 確定文と途中の判定

113 件の `final` の `id`、`lang`、`text` は、4 本の run で全部同じである。
`id` ごとに並べて `diff` し、1 行を書き換えた陽性対照は 2 行の差を出した。

途中の言語判定（`asr.partial.lang.asked`）は、a、e、b のそれぞれで 85 件あり、`lid_ms` の p50 は 54 から 56 ms、p95 は 60 から 90 ms だった（c は旗を外したので 0 件）。
85 件の答えを、答えの後に最初に終わる `final` の言語と比べると、82 件が同じで、3 件（`file-17`、`file-54`、`file-91`）が違った。
3 件とも日本語の発話を `en` と聞いた。
最初の発話（`file-1`、冷えた標本）には途中の判定が無い。
log の時刻は秒の刻みなので、突き合わせは `file-1` の前後で 1 件ずれうる（e では実際にずれ、`file-1` が加わって 4 件になる）。
