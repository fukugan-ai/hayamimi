# RP-13 の訳と V の止めすぎの診断

V を掛けなければ、4 言語とも訳は RP-13 の記録を超える。記録を割るのは、V が正しい訳まで止めて、その行が空の hyp になるからである。

条件は次のとおり。
文は `testdata/baseline/pairs/` の FLEURS 50 組（`fleurs-pairs --n 50 --seed 0`）。
訳は ja から各言語へ、T だけ（E も V も掛けない）。en は CAT-Translate-3.3b、zh、ko、es は TranslateGemma-4B-it Q8_0（ja→zh は ja→ko、ja→es と同じ形）。
V は `hayamimi-relay` の組み込みの表（native `Verifier::verify_into`）。
測った日は 2026-10-14。coder 席の使い捨ての crate で測り、repo には入れていない。

## V を掛けない全行の chrF

`hayamimi-eval chrf --pairs testdata/baseline/pairs --hyps <T だけの hyp>` の出力。

| 言語 | 記録 | V なし | V あり、止めた行は空（`rp13_translation.md`） |
|---|---|---|---|
| en | 47.57 | 54.29 | 44.56 |
| es | 42.09 | 45.79 | 35.87 |
| ko | 25.20 | 27.76 | 22.78 |
| zh | 20.19 | 28.78 | 16.52 |

「V あり」の en は T の後に E を掛けた訳で、「V なし」の en は T の下書きだけである。
2 つの列は同じ訳ではないので、差のすべてが V の効果ではない。

## 止めた行の理由

どの行も 50 行中の数。数は、V を掛けた各行の判定を理由ごとに数えた。

| 言語 | 訳（T だけ）の止めた行 | 参照訳の止めた行 |
|---|---|---|
| en | 15（uncertainty 6、number 4、negation 2、form 2、proper_noun 1） | 14（number 6、negation 4、uncertainty 3、proper_noun 1） |
| zh | 18（negation 7、number 6、uncertainty 4、proper_noun 1） | 20（number 8、negation 7、uncertainty 4、proper_noun 1） |
| ko | 13（negation 8、uncertainty 2、number 2、form 1） | 14（negation 6、uncertainty 4、number 2、form 1、proper_noun 1） |
| es | 15（number 10、uncertainty 3、negation 1、form 1） | 22（number 15、uncertainty 3、negation 2、proper_noun 2） |

参照訳は人手の正しい訳である。参照訳が 14 から 22 行止まるので、V は正しい訳を 28% から 44% 止めている。
会話字幕の CS-24 は、この数を 0 にする条件である。

## 表では直せない 2 つの型

評議へ戻す型の数。行は pairs の行番号。

| 型 | 参照訳 | 訳（T だけ） |
|---|---|---|
| 含意の否定「もってのほか」（原文に否定の標識が無く、訳が `Do not` や「不要」のように否定語で書く） | 3 行（en、zh、es の 18 行目。ko は止まらない） | 1 行（zh の 18 行目） |
| 含意の否定 `failed to`（原文は `上がれませんでした` で否定の標識があり、訳の `failed to` は否定語の表に無い） | 1 行（en の 48 行目） | 0 行 |
| 伝聞の「そうです」（原文の `そうです` を推量の標識に数え、訳に推量の語が出ない） | 3 行（en、zh、es の 50 行目。ko は止まらない） | 3 行（en、zh、es の 50 行目） |

3 つの型は、原文側か訳の側の一方にしか標識が出ない。
このため、片側の表だけを足しても直らず、原文側と訳の側の表の両方へ標識を足して直した（次の節）。

## V の直し

直した所は、数の読み（`numbers.rs`、`spelled.rs`）、標識の表（`verify_markers.toml`）、固有名の語（`verify.rs`）である。
閾値と、標識が片側にしか無い行を止める規則は変えていない。

| 直した型 | 内容 |
|---|---|
| `tenía`、`entorno` が数の `ten` になる | 英語の数語は、非 ASCII の字が続く語の頭を数語に取らない |
| `km2`、`4892m` | 長さの単位の 2 乗と、数と単位の組は、数でも固有名でもない |
| `19 500` | 3 桁ごとの空白区切りを 1 つの数に読む |
| `12月` と `December` | 月名を月の数として読む（英語は頭が大文字、スペイン語は小文字） |
| `两`、`百分之八十` | `两` を 2、`亿` を億に読み、`百分之` の `百` を数に取らない |
| `dos`、`treinta y cinco`、`ochenta por ciento` | スペイン語の数語を読み、`por ciento` の `ciento` は 100 に取らない |
| `thirteenth`、`twenty-fourth` | 英語の序数を読む（`first` と `second` は `thirty-first` の形のときだけ） |
| `もってのほか`、`failed to`、`rarely` | 原文の含意の否定と訳の否定語を、両側の表へ足す |
| `たそうです`、`るそうです` | 伝聞の「そうです」は推量に数えない（`降りそうです` は数える） |
| `about the`、`around the` | `about` と `around` は、冠詞か代名詞の前では推量に数えない |
| `分别`、`特别`、`不仅`、`not only`、`だけでなく` | 否定の字を含むだけの語と、「だけでなく」型を否定に数えない |
| `ほど`、`程度`、`およそ`、`前後`、`ほぼ` | 原文の概数の語を推量に数える（`後ほど`、`それほど`、`なるほど` は除く） |

数語、月名、序数の表は、その言語の訳に対してだけ読む（英語の `once` を 11 と読まない）。
対照は、数を変えた訳（`7,500 km²`、`June`、`tres horas`、`有三个人`）と、否定や推量を落とした訳（`Make jokes.`、`The team reached the final.`、`It is raining.`）が、今も止まることである。

## 4 言語の chrF

seed 0 の 50 組に、T だけの訳（E は掛けない）を V に通し、止めた行を空にして測った。

| 言語 | 記録 | V なし | V あり 直す前 | V あり 直した後 |
|---|---|---|---|---|
| en | 47.57 | 54.29 | 42.04 | 46.65 |
| es | 42.09 | 45.79 | 35.87 | 39.17 |
| ko | 25.20 | 27.76 | 22.78 | 23.38 |
| zh | 20.19 | 28.78 | 16.52 | 22.50 |

V ありで記録を超えるのは zh だけである。
en、es、ko は V なしなら記録を超えるが、V ありでは記録に届かない。
参照訳の止まる行は 200 行中 30 行（15%）残り、会話字幕の CS-24 の 0 行には届かない。

## ja から en の live で V に落ちる行

R8e と同じ形（`hayamimi --input ws`、`hayamimi-relay live`、`hayamimi-eval stream --wav lat-ja.wav`、CAT-Translate-3.3b、`--min-silence 0.30`）で、直す前の中継と直した後の中継を、同じ認識と同じ server で 1 回ずつ流した。
繰り返しは R8e の 5 回でなく 3 回で、`final` は 75 件である。
他の席が同じ機械を使っている間の値で、無負荷の値ではない。

| | 直す前 | 直した後 |
|---|---|---|
| T の訳が V に落ち、速報の訳が出なかった `final` | 32 / 75（43%） | 23 / 75（31%） |
| E の後も V に落ち、確定の訳が `held` の `final` | 19 / 75（25%） | 10 / 75（13%） |
| `final` から速報の訳まで（V を通った行）の p50 | 191 ms（n 43） | 200 ms（n 52） |
| `final` から確定の訳まで p50 | 496 ms | 512 ms |
| `L`（発話の終わりから訳の字幕）p50 / p95 | 1433 / 2088 ms（n 60） | 1450 / 1839 ms（n 60） |
| `L_tr` p50 / p95 | 333 / 1093 ms | 315 / 789 ms |

V に落ちる行は 43% から 31% に減り、`held` で訳が出ない行は 25% から 13% に減った。
`L` の p50 は動いていない（1433 ms と 1450 ms）。
`L` の大半は認識の待ち（R8e の `L_asr` p50 は 1270 ms）で、V を通った行の訳の遅れも変わっていないので、V を直しても `L` の p50 は縮まない。
縮んだのは `L_tr` の p95（1093 ms から 789 ms）で、E を待つ行が減った分と読めるが、1 回ずつの run なので確かめていない（NOT VERIFIED）。
p50 の差 17 ms は揺れの内にある。

## 表では直らない行

- 参照訳が、原文に無い否定や推量を書く、または原文の標識を訳さない行（zh の `而不是` と `并不少见`、ko の `낡지 않을지라도`）
- ローマ数字（`Luis XVI`）、世紀の言い方（`20 世纪 70 年代`）、スペイン語の序数（`vigésimo cuarto`）、韓国語の数詞（`팔십`、`열여덟`、`수천`）は、数として読めていない。
- `珍しくありません` を `common` と訳す型は、否定が二重で、表の足し引きでは片方が直ると片方が止まる。
